Quick answers

Can I get banned for using it?

The app only uses the official Live Client API that Riot provides for companion apps (the same way other well-known apps work) plus screenshots. It never reads or writes game memory, never sends key presses and never picks augments for you. Still, it is a third-party tool – use it at your own discretion under Riot's current policies.

Does it eat RAM or hurt my FPS?

It is light: about 70–90 MB of RAM while running, and the overlay is a single transparent window, so FPS is not noticeably affected.

Where do the stats come from, and how fresh are they?

Augment and item stats come from playaram.gg; names and icons from Riot Data Dragon and CommunityDragon. The app refreshes its data when you open it.

What if it does not read my augments automatically?

You can still look things up: type a champion or augment name in the search box to see stats and advice. While the augment cards are open, press Ctrl+Alt+A to make the app find the cards again.
